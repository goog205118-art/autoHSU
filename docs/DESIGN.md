# 社媒工作室界面约定

2026-11-11。使用项目已安装的 frontend-design 技能，参考本地 gptimagemt 的 DESIGN.md、base.css 和 workspace.css。

面向以产品参考图制作欧美社媒贴文的创作者，主要任务是持续调整输入、生成文案和成组配图。采用 gptimagemt 的浅色灰阶、统一线性图标、清晰边界与图像优先原则。原参考中的浮层交互按本任务要求改为文档流中的完整页面。

## 色彩与字体

| 用途 | 颜色 |
| --- | --- |
| 页面 | #fcfcfc |
| 面板 | #ffffff |
| 预览衬底 | #f4f4f4 |
| 正文 | #242424 |
| 次要文字 | #686868 |
| 分隔线 | #e7e7e7 |

主要动作使用深灰；成功和错误仅用于状态反馈。字体为 Segoe UI、PingFang SC、Microsoft YaHei 的本地字体栈，标题 19–20px，控件 12–13px，手机输入 16px。图标是内联 SVG，无远程字体依赖。

## 布局

导航、工作区和主体共用最大 1520px 外框，其中内容区最大 1440px，左右留白 16–40px。桌面主体为 5:7 两栏，所有标题、面板和下方内容与各自列边缘对齐；800px 及以下改为单列，560px 及以下顶栏分两行，模板和比例上下排列。

```text
品牌与标题                         API 状态 / 导出 / 设置
工作区   创作 01   创作 02   ＋
开始创作                            内容预览
产品参考图                          社媒贴文 / 复制
内容需求、模板、逐图比例             配图作品
生成                                单图重试、详情、导出
生成进度与记录（可展开）
```

设置和配图详情在同一外框内替换主体，不使用浮窗、遮罩或内部定高滚动容器。返回时恢复原滚动位置和键盘焦点。工作区过多时仅导航列表横向滚动，新增按钮保持可用。

## 取舍与验收

保留社媒贴文的实际结构作为视觉重点。去掉原欢迎页、蓝色渐变、叠加注入样式与全局工作台关闭按钮；用统一静态样式表管理布局。空态指导上传和生成，不伪造已有作品。记录默认折叠，避免干扰创作。

可见键盘焦点、跳转链接、逐图控件名称、单击与 Enter/Space 预览、Escape 返回、键盘上传和减少动态效果均有覆盖。截图和验证结果见 VALIDATION.md。
