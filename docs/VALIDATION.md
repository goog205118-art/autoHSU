# 验证记录

验证日期：2026-11-11。接口及构建检查使用 Node.js 22.23.4 和 24，浏览器验收使用 Chromium 自动化完成。

## 接口测试

执行 `node --test tests/api.test.mjs`，12 项全部通过。所有上游请求由本机测试服务或进程内 mock 模拟，不消耗真实模型额度。

1. 演示模式无密钥运行、静态资源完整、公开配置不泄露密钥、私有配置文件不可访问。
2. 真实模式缺少配置时返回明确错误，不退回演示数据。
3. Gemini 文字与图片原生请求，验证所有商品参考图、请求头和单图比例。
4. Compatible 文字请求及 multipart 图像编辑请求，验证参考图文件、模型参数和结果归一化。
5. 自定义异步任务轮询、任务 ID 编码、处理中不重复返回 ID 的场景、本机图片代理读取。
6. 鉴权错误信息去除密钥、无效 JSON 内容字段、失败任务、轮询超时。
7. 非法上传格式、无图请求、非法比例、无效 JSON、来源检查及未知接口。
8. 线上访问口令、HttpOnly/Secure 会话、错误口令、来源检查及会话跨函数实例。
9. 加密图片令牌跨实例读取和篡改拦截。
10. 大于 4.5 MB 的 Base64 图片结果通过分块响应完整返回。
11. Vercel API 路由重写和演示图片查询参数。
12. 固定时钟并模拟请求头/响应体读取阶段超时，分别验证任务总期限、较短的单次请求期限和连接错误，避免依赖毫秒级调度。

## 构建失败回归

用户提供的 Vercel 截图显示 Node.js 22.23.4 下接口测试进程退出 1，未包含失败断言的上文。本机用相同 Node 版本单次运行通过；24 个测试进程并发运行时，旧版有 2 次失败，均为 10 毫秒轮询期限在请求途中耗尽，实际返回“上游 API 请求超时”，与预期“任务轮询超时”不一致。

现已修正期限分类：由任务剩余时间限制的请求超时统一报告任务轮询超时，独立的较短请求期限和其他网络错误保持各自含义。响应体读取也纳入同一超时处理。构建继续执行完整接口测试，没有跳过失败用例。

修复后 Node.js 22.23.4 在 `VERCEL=1`、`CI=1` 下构建通过，24 个测试进程并发运行共 288 项检查全部通过；Node.js 24 构建也通过。实际 Vercel 构建状态需以推送后的部署结果为准。

- 新增工作区、切换工作区、输入恢复。

- 单图重新生成，配图卡片数量不增加。
- 模拟上游单图失败，其他配图成功，失败提示可见，单独重试后恢复成功。
- 模板新增、删除，设置和模板在页面刷新后保留。
- 文案及标签复制到剪贴板。
- 双击配图预览及关闭。

- 访问口令登录、错误口令提示、刷新后的登录恢复。
