# 验证记录

当前版本为网页直连版。使用 Node.js 22.23.4 和 Chromium 验证；所有上游由本地测试服务或进程内 mock 提供，没有调用真实收费模型。

## 构建与接口

执行 `node scripts/check.mjs`，先进行全部 JavaScript 语法检查，再运行 `tests/direct-api.test.mjs`。11 项测试覆盖：

1. 无 Key、无后端时可读取页面连接状态，不自动请求模型。
2. Key 默认仅驻留内存；勾选记住后可恢复；取消勾选清除两个已存 Key。
3. 地址/Key/超时校验，以及存储失败不覆盖当前连接。
4. Responses 多模态请求和 message 输出解析。
5. 独立文案连接、Chat Completions 及 JSON 代码块解析。
6. GPT Image multipart 重复 image 字段、原图字节、尺寸、格式与 Bearer 鉴权。
7. 旧模型尺寸及输入保真参数、2.5 质量与提示词长度、手动格式字段。
8. 鉴权错误、超时与断网不自动重发，错误信息隐藏当前 Key。
9. 非法参考图、比例及无效文案字段的提示。
10. 模型读取为只读 GET，请求不改变保存的连接。
11. 静态资源可访问、没有登录入口/环境变量样例/API handlers、部署无云函数和 API rewrites。

## 浏览器验收

执行 `tests/page-smoke.mjs`，Chromium 页面连接实际本地跨域 mock 服务；该服务处理 CORS 预检并解析上传的 multipart。已通过：

- 打开直接进入工作台，没有网站密码遮罩，没有启动时的模型请求。
- 缺少 Key 时生成操作打开设置，不发送请求。
- 页面填写 API 地址、Key 和文案模型，读取模型列表、显示/隐藏 Key。
- 同时上传 5 张商品参考图，验证每张原始字节完整到达 mock。
- 多工作区切换并恢复输入。
- Responses 生成文案，1:1、4:5、9:16 分别以 1024x1024、1024x1280、720x1280 提交图片请求。
- 三张图片成功显示，复制正文与标签，双击图片预览。
- 模拟单图 429，确认不自动重发，点击重试后成功；共 5 次图片请求。
- 通过浏览器内模拟目录句柄验证导出 copy.txt 与 3 张 PNG。
- 保存并刷新可恢复勾选记住的两个 Key；取消勾选保存，再刷新后两个 Key 均为空。
- 桌面 1440px 与手机 390px 布局；手机工作台与设置页没有横向溢出。
- 无页面 JavaScript 错误。

预览为 preview-desktop.png 和 preview-mobile.png。测试 Key 为固定的虚构值；预览中的图片和文案来自 mock，不代表真实模型输出。

浏览器验收需提供 Playwright 及 Chromium，不属于线上依赖。文件夹导出使用模拟句柄，没有操作系统原生目录选择器的自动化验收。

## 真实联调边界

尚未收到真实供应商 Key，未验证账户权限、余额、实际模型可用性或生成质量。默认地址和模型名来自用户指定的 gptimagemt 仓库版本；具体可用性须以当前 Key 为准。

纯网页直连依赖服务商允许浏览器跨域访问。此版本不转发请求，不绕过供应商的 CORS 策略，也不包含 Vercel 函数。
